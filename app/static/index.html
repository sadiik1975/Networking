Contractor Discovery & Matching

A connector project for searching construction leads, finding relevant contractors, and supporting dispatch workflows.

What we're building

Construction discovery, made easier to work with.

The project brings lead search and contractor matching together behind an API that software and AI assistants can use.

01 / DISCOVER

Search local opportunities

Explore construction leads by trade, location, distance, and project value.

02 / MATCH

Find a relevant fit

Compare a project's trade and location with contractor service areas.

03 / CONNECT

Build for assistant workflows

REST API and MCP tools let compatible assistants search and retrieve project information.

About Been Ventures

Been Ventures Inc. is an independent business exploring practical software for construction discovery and coordination. Its current project focuses on making structured project and contractor information accessible through modern APIs.

The connector is being developed with a focus on clear workflows: search first, review matches, then coordinate with confirmation. Outreach is queued rather than automatically sent.
